# Propertyの定義
- ある処理で想定されるすべての入力と出力について、常に真である性質
- 例
    - sort処理
        - 入出力の配列の長さは同じ
        - 隣り合う2要素xi, xjについて、常に xi <= xjが成り立つ
    - 配列の最後の値を取得する処理
        - 出力は配列の最大インデックスの値と等しい
    - 配列内の最大値を取得する処理
        - 出力は配列内の最大の値と等しい

# 問題点
- Property記述に用いる処理をどこまで信用するか
    - 信用 = 常に意図した処理を行なっているのかの検証を行わないこと

# 主要なPropertyの定義の手法
- モデル
    - 入出力の処理をより簡単な処理で書く
- 不変条件
    - 入出力の前後で常に真となる性質
- 対称プロパティ
    - 順方向の処理と逆方向の処理がある場合に用いる
    - 元の入力と逆方向(順方向(入力))が一致するか
